# Courses

- [Full Stack Open](https://fullstackopen.com/en/) — React, Node.js, testing, TypeScript.
- [Next.js Learn](https://nextjs.org/learn) — official Next.js learning path.
- [web.dev Learn](https://web.dev/learn) — web platform, performance, accessibility.
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) — practical web security.
- [Docker Curriculum](https://docker-curriculum.com/) — Docker basics.

## Как использовать

Курсы не являются источником production-решений сами по себе. Используй их для обучения и проверки терминологии, а финальные рекомендации сверяй с официальной документацией, security checklist и реальными case studies из этой вики.
