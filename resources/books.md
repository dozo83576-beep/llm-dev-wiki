# Books

- Designing Data-Intensive Applications, Martin Kleppmann — advanced, architecture/data systems.
- Clean Architecture, Robert C. Martin — intermediate, software boundaries.
- Refactoring, Martin Fowler — intermediate, improving existing code safely.
- Domain-Driven Design, Eric Evans — advanced, complex domains.
- Web Application Security, Andrew Hoffman — intermediate, web security.
- Site Reliability Engineering, Google — advanced, production reliability.

Книги не заменяют официальную документацию конкретных библиотек; используй их для архитектурных принципов.
