# Books

- [Designing Data-Intensive Applications](https://dataintensive.net/), Martin Kleppmann — advanced, architecture/data systems.
- [Clean Architecture](https://www.pearson.com/en-us/subject-catalog/p/clean-architecture-a-craftsmans-guide-to-software-structure-and-design/P200000009528), Robert C. Martin — intermediate, software boundaries.
- [Refactoring](https://martinfowler.com/books/refactoring.html), Martin Fowler — intermediate, improving existing code safely.
- [Domain-Driven Design](https://www.domainlanguage.com/ddd/), Eric Evans — advanced, complex domains.
- [Web Application Security](https://www.oreilly.com/library/view/web-application-security/9781492053101/), Andrew Hoffman — intermediate, web security.
- [Site Reliability Engineering](https://sre.google/sre-book/table-of-contents/), Google — advanced, production reliability.

Книги не заменяют официальную документацию конкретных библиотек; используй их для архитектурных принципов.
