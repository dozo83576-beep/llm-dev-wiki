# Design inspiration / референс-галереи

Курированный список галерей, куда Клод идёт за дизайн-референсами под бриф, когда у пользователя нет
своих. Сгруппировано по назначению. **Правило: извлекать ДНК** (типографика, ритм, палитра, spacing,
структура) — **не копировать вёрстку, тексты, бренд и не скачивать платные шрифты** с этих сайтов
(см. лицензии в [Typography-fonts](../docs/02-frontend/Typography-fonts.md)).

## Как использовать (для агента)

1. Нет референсов у пользователя → по нише/настроению брифа открой 1–3 галереи ниже (WebFetch/WebSearch),
   собери 3–6 примеров.
2. Извлеки ДНК каждого: гарнитуры и веса, line-height, палитра, spacing/воздух, hero-архетип, ритм секций.
3. Сложи извлечённое в `<design_direction>` артефакта и предложи 3–4 направления (см.
   [design-direction-brief](../prompts/design-direction-brief.md)).
4. Сверь шрифты с каталогом и кириллицей; платный шрифт референса → free-лукалайк.

## Craft / visual (award-уровень)

- [Awwwards](https://www.awwwards.com) — эталон award-сайтов; судят дизайн, юзабилити, креатив.
- [Godly](https://godly.website) — тугая курация, силён по motion (главный дифференциатор 2026).
- [recent.design](https://recent.design) — свежие отобранные сайты.
- [The FWA](https://thefwa.com), [CSS Design Awards](https://www.cssdesignawards.com) — ещё award-галереи.

## Landing / продающие страницы

## Компоненты (готовый код)

## Общие портфолио-галереи

- [Behance](https://www.behance.net), [Dribbble](https://dribbble.com) — широкий поток; брать концепты
  и визуальные ходы, помня что это часто нереализованные макеты (проверяй на жизнеспособность в вебе).

## Fonts in use (что за шрифт на сайте)

- [Typewolf](https://www.typewolf.com) — тренды и «какой это шрифт»; подбор пар.
- [Fonts In Use](https://fontsinuse.com) — каталог реального применения шрифтов.

## Правила (важно)

- Извлекать принципы, не копировать вёрстку/контент/бренд.
- Не скачивать и не переиспользовать платные шрифты/ассеты с этих сайтов; только определить вайб →
  free-аналог (OFL/Fontshare) из [Typography-fonts](../docs/02-frontend/Typography-fonts.md).
- Не сохранять чужой брендовый контент в вики/проект как свой.
- Галереи — источник вкуса, не источник production-решений по технологиям; код/стек сверяй с вики.
