# Design inspiration / референс-галереи

Курированный список галерей для актуальных дизайн-референсов, когда предоставленного контекста
недостаточно. Сгруппировано по назначению. **Правило: извлекать ДНК** (типографика, ритм, палитра, spacing,
структура) — **не копировать вёрстку, тексты, бренд и не скачивать платные шрифты** с этих сайтов
(см. лицензии в [Typography-fonts](../docs/02-frontend/Typography-fonts.md)).

## Как использовать (для агента)

1. Ищи внешние референсы только когда без актуального evidence нельзя уверенно выбрать направление.
2. Открой достаточную для решения выборку и извлеки типографику, палитру, spacing, структуру, motion
   и image language; количество определяется разнообразием evidence, а не квотой.
3. Сформулируй одно направление по [design-direction-brief](../prompts/design-direction-brief.md).
   Альтернативы нужны только при материальной неопределённости.
4. Сверь шрифты с каталогом, кириллицей и лицензией; платный шрифт референса замени допустимым аналогом.

## Craft / visual (award-уровень)

- [Refero Styles](https://styles.refero.design/) — AI-readable `DESIGN.md` примеры из продуктовых сайтов:
  цвета, типографика, spacing, компоненты, motion/illustration/graphic DNA для Codex/Claude/v0. Используй как
  источник направления, не как шаблон для копирования.
- [Awwwards](https://www.awwwards.com) — эталон award-сайтов; судят дизайн, юзабилити, креатив.
- [Godly](https://godly.website) — тугая курация, силён по motion (главный дифференциатор 2026).
- [recent.design](https://recent.design) — свежие отобранные сайты.
- [The FWA](https://thefwa.com), [CSS Design Awards](https://www.cssdesignawards.com) — ещё award-галереи.

## Landing / продающие страницы

- [Land-book](https://land-book.com) — лендинги и SaaS-страницы.
- [Lapa Ninja](https://www.lapa.ninja) — каталог лендингов по категориям.
- [Httpster](https://httpster.net) — живые сайты, неприлизанная подборка.
- [supahero.io](https://supahero.io) — секции и hero-паттерны.

## UI-паттерны / реальные продукты

- [Mobbin](https://mobbin.com) — реальные экраны и флоу веб/мобайл-приложений (UX-референс).
- [Refero](https://refero.design) — UI реальных продуктов с поиском по паттернам.

## Компоненты (готовый код)

- [21st.dev](https://21st.dev/community/components) — community React/Tailwind компоненты (см. также
  [Premium-components](../docs/02-frontend/Premium-components.md)).

## Общие портфолио-галереи

- [Behance](https://www.behance.net), [Dribbble](https://dribbble.com) — широкий поток; брать концепты
  и визуальные ходы, помня что это часто нереализованные макеты (проверяй на жизнеспособность в вебе).

## Fonts in use (что за шрифт на сайте)

- [Typewolf](https://www.typewolf.com) — тренды и «какой это шрифт»; подбор пар.
- [Fonts In Use](https://fontsinuse.com) — каталог реального применения шрифтов.

## Правила (важно)

- Извлекать принципы, не копировать вёрстку/контент/бренд.
- Не скачивать и не переиспользовать платные шрифты/ассеты с этих сайтов; только определить вайб →
  free-аналог (OFL/Fontshare) из [Typography-fonts](../docs/02-frontend/Typography-fonts.md).
- Не сохранять чужой брендовый контент в вики/проект как свой.
- Галереи — источник вкуса, не источник production-решений по технологиям; код/стек сверяй с вики.
