# Newsletters

- [Bytes](https://bytes.dev/) — JavaScript ecosystem.
- [React Status](https://react.statuscode.com/) — React updates.
- [Postgres Weekly](https://postgresweekly.com/) — PostgreSQL ecosystem.
- [SRE Weekly](https://sreweekly.com/) — reliability and operations.
- [TLDR Web Dev](https://tldr.tech/webdev) — broad web development updates.

Newsletter-сигналы нужно проверять по официальным источникам перед внесением в вики.

## Как использовать

Newsletter подходит для раннего обнаружения изменений в экосистеме, но не для автоматического обновления рекомендаций. Перед правкой production-документа проверь release notes, migration guide, security advisory и влияние на текущие stack/playbook документы.
