# Site stack

Входы: discovery, primary playbook, архитектурные ограничения и существующая кодовая база.

По умолчанию выбирай простейший стек, закрывающий требования; для статического публичного сайта в D:\Work это Astro. CMS, auth и серверная логика добавляются только при подтверждённой необходимости.

Актуальные версии, лицензии, support status и security guidance проверяй по официальным источникам внешним инструментом. Сравнивай альтернативы только если различие влияет на решение.

В `_stack.md` запиши выбор и версию, основания, отклонённые варианты, runtime/deploy constraints и команды проверки. Не помещай секреты в примеры конфигурации. Решение считается подтвержденным после проверки совместимости с проектом.
