# Site handoff

Собери сведения из подтверждённых фаз, review и deploy evidence. Не повторяй заявления, которые не подтверждены свежей проверкой.

`handoff.md` должен содержать:

- что поставлено и что осталось вне scope;
- как запустить, проверить, обновить и откатить;
- окружения, внешние зависимости и владельцев без самих секретов;
- результаты приёмки, известные ограничения и monitoring;
- действия владельца только там, где они действительно нужны.

Критичные доступы передаются безопасным каналом и подтверждаются вторым каналом. Production-статус называй только фактическим. При необходимости добавь `_post-release-plan.md` с измеримыми проверками после релиза.
