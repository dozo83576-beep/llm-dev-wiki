# Capture learnings

Используй для устойчивого правила, проверенного failure pattern или одобренного предпочтения. Разовую деталь проекта не превращай в канон.

## Порядок

1. Сформулируй кандидат и evidence, отделив факт от вывода.
2. Выбери место: публичная вики, локальное предпочтение или не сохранять.
3. Покажи пользователю формулировку и дождись подтверждения.
4. Сначала выполни dry-run поддерживаемого update-механизма, затем применяй.
5. Запиши `_learning-review.md`: решение, источник, область действия и проверку.

Не сохраняй секреты, ПДн, закрытые данные клиентов и непроверенные правовые утверждения. Для ПДн действует 152-ФЗ и обезличивание. После изменения вики выполни её локальный gate.
