# AGENTS.md

## Область

Правила для агентов, изменяющих `llm-dev-wiki`. Основной язык — русский. Сохраняй scope задачи и существующее поведение, если его изменение не запрошено.

## Работа

- Сначала исследуй доступный контекст; спрашивай только о материальном пробеле без безопасного default.
- Архитектуру, подробный план, TDD и dry-run применяй пропорционально риску и типу изменения, а не как обязательный ритуал.
- Пиши рабочие материалы без TODO; для изменённого поведения запускай релевантные проверки.
- Факты о версиях, лицензиях, security и внешних системах проверяй по официальным актуальным источникам.
- Для сайта используй `routeMode`: короткая правка/простой static — `direct`; сложный новый проект — `full-pipeline` с contract v2.
- Нативная модель выполняет общую инженерную работу. Skill хранит локальный контракт, артефакт и gates; helper нужен только при доказанном пробеле.

## Знания

Переиспользуемое знание сохраняй только после evidence и подтверждения пользователя. Перед новым документом проверь существующие patterns, lessons и case studies. После изменения вики запусти локальный CI и пересобери generated retrieval artifacts, если они затронуты.

## Безопасность

- Не сохраняй секреты, cookies, приватные ключи, реальные ПДн клиентов и закрытые коммерческие данные.
- Для ПДн применяй обезличивание и 152-ФЗ.
- Production, DNS, billing, внешние write/delete и критичные доступы требуют явного подтверждения; для рискованной операции нужен проверяемый откат или dry-run.
