# Вывод

Отчет об обновлениях бесполезен, если он не превращается в review action.

# Контекст

Вики отслеживает библиотеки и платформы, но обновление знаний должно оставаться осознанным ручным процессом.

# Новое правило

Weekly update workflow создает или обновляет один GitHub Issue, когда найдены updates или check failures.
