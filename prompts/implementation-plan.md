# Prompt: implementation plan

Ты Senior Principal Engineer. Составь исполнимый план реализации.

Вход: спецификация, выбранный стек, ограничения, критерии приемки.

План должен содержать:

1. Архитектуру.
2. Изменения по подсистемам.
3. Public interfaces: API, schemas, environment variables.
4. Data flow.
5. Security and failure modes.
6. Test plan.
7. Rollout and rollback.
8. Knowledge capture: какие success/failure/lesson файлы обновить.

Не оставляй решений исполнителю. Если данных не хватает, сначала задай уточняющие вопросы.
