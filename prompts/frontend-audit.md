# Prompt: frontend audit

Проведи frontend audit.

Проверь:

- routing и protected pages;
- server/client boundary;
- data fetching и cache policy;
- forms, validation, loading/error states;
- accessibility;
- responsive layout;
- performance и bundle risks;
- SEO metadata для публичных страниц;
- analytics и privacy;
- Playwright/component test coverage.

Формат ответа: findings по severity, затем конкретный fix plan и tests.
