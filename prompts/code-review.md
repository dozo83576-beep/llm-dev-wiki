# Prompt: code review

Проведи code review в инженерном стиле.

Сначала находки по severity с файлом и строкой. Приоритет: баги, security, data loss, broken auth, race conditions, memory leaks, regressions, missing tests. Затем коротко: открытые вопросы, summary, рекомендуемые проверки.

Не хвали код вместо анализа.
