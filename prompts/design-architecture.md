# Prompt: design architecture

Спроектируй архитектуру web-приложения.

Требуется: компоненты, границы ответственности, data flow, API contracts, database model, auth/authz, background jobs, external integrations, deploy topology, observability, security risks, testing strategy.

Архитектура должна быть проверяемой: перечисли acceptance scenarios и команды/проверки для реализации.
