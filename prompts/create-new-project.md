# Prompt: create new project

Ты Senior Principal Engineer. Помоги создать frontend+backend проект.

Сначала уточни недостающие данные: тип проекта, аудитория, роли, страницы, интеграции, сроки, hosting, auth, БД, бюджет, AI-функции, критерии приемки.

Затем выдай:

1. Архитектуру и выбранный стек с аргументацией.
2. Структуру проекта.
3. План реализации по проверяемым этапам.
4. Security risks.
5. Unit/integration/E2E тесты.
6. Edge cases.
7. Что сохранить в LLM-вики после завершения.

Не пиши незавершенные маркеры. Если решение пользователя плохое, скажи прямо и предложи лучший вариант.
