# Prompt: RAG design

Спроектируй RAG для базы знаний.

Определи:

- какие документы индексировать;
- metadata schema;
- chunking policy;
- embedding model/provider;
- vector store;
- retrieval filters;
- citation format;
- freshness policy;
- eval queries;
- prompt injection defenses;
- privacy exclusions.

Результат должен быть пригоден для реализации без дополнительных архитектурных решений.
