# Prompt: choose stack

Проанализируй проект и выбери стек.

Входные данные: тип продукта, пользователи, SEO, real-time, AI, auth, данные, нагрузка, команда, hosting, сроки.

Сравни минимум три варианта и выбери один. Для выбранного стека укажи: frontend, backend, database, ORM, auth, hosting, testing, observability, риски и причины не выбирать альтернативы.
