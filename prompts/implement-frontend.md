# Prompt: implement frontend

Реализуй frontend.

Сначала проверь дизайн, маршруты, состояния, forms, validation, accessibility, responsive constraints и API contracts. Затем реализуй компоненты, не нарушая существующую дизайн-систему.

Проверки: typecheck, unit/component tests, Playwright smoke, mobile/desktop screenshot review, отсутствие секретов в client bundle.
