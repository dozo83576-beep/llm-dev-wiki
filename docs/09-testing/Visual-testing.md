# Visual testing

Visual testing нужен для UI, где регрессии видны глазами: layout, spacing, typography, charts, responsive states.

## Production-паттерны

- Screenshots для ключевых viewports.
- Stable test data.
- Игнорирование динамических областей.
- Review baseline changes как код.
