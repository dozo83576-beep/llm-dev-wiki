# Accessibility testing

Accessibility testing сочетает automated checks и ручную keyboard/screen-reader проверку.

## Проверки

- Semantic HTML.
- Keyboard navigation.
- Focus visible.
- Labels и error messages.
- Contrast.
- Reduced motion.

Источник: [WCAG 2.2](https://www.w3.org/TR/WCAG22/), [axe DevTools](https://www.deque.com/axe/devtools/).
