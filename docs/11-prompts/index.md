# Prompts

Готовые промпты находятся в `prompts/`:

- создание проекта;
- выбор стека;
- архитектура;
- дизайн БД;
- frontend/backend implementation;
- тесты;
- code review;
- debugging;
- refactoring;
- security review;
- deploy;
- обновление вики.

Перед использованием промпта добавь конкретный контекст проекта: стек, версии, окружение, ограничения и критерии приемки.
