## Общий Definition of Done

- Цель, аудитория и acceptance criteria зафиксированы.
- Стек выбран и обоснован.
- Security review пройден.
- Тесты покрывают критичные сценарии.
- Deploy и rollback понятны.
- Уроки проекта сохранены в `case-studies` или `lessons-learned`.
