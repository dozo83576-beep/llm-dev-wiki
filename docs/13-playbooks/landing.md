# Playbook: Landing

## Стек по умолчанию

Astro или Next.js, Tailwind, forms endpoint, analytics, SEO metadata, Lighthouse checks.

## Порядок разработки

1. Offer: кому, какую проблему решает, какой CTA.
2. Content: hero, proof, features, objections, FAQ, CTA.
3. SEO: title, description, headings, structured data при необходимости.
4. UI: responsive, visual asset, fast first viewport.
5. Forms: validation, spam protection, notification, storage.
6. Analytics: page view, CTA click, form submit, conversion.
7. Performance: image optimization, Core Web Vitals.

## Анти-паттерны

- Делать hero без реального продукта/объекта.
- Добавлять тяжелый frontend framework без интерактивной потребности.
- Не проверять mobile first viewport.
