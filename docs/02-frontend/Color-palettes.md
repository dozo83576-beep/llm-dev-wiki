# Цветовые палитры и токены

## Назначение

Каталог не-дефолтных цветовых направлений под ниши/настроения, готовых к вставке как CSS-токены
**по поверхностям** (не один глобальный `--text`). Цель — быстро взять характерную палитру вместо
дефолтного кремового/serif или фиолетово-синего градиента. Дополняет
[Anti-AI-slop design](../../patterns/frontend/anti-ai-slop-design.md) и
[Semantic theme text tokens](../../patterns/frontend/semantic-theme-text-tokens.md).

## Когда использовать

- Подбор палитры под лендинг/продукт в [design-direction-brief](../../prompts/design-direction-brief.md).
- Нужно перебить дефолтный house style модели конкретными hex, а не «тёмный с акцентом».
- Есть референс — извлечь палитру (ДНК), а не один доминирующий цвет.

## Когда не использовать

- Жёсткий бренд-гайд клиента уже задаёт цвета — следуй ему.
- Дашборд с плотными данными — там семантические статус-цвета важнее «вайба» (см. [Design-systems](Design-systems.md)).

## Production-паттерны

### Принцип: токены по поверхностям

Не `--text` на всё. Минимум: фон-поверхности + текст под каждую поверхность + акцент. Полное правило —
[Semantic theme text tokens](../../patterns/frontend/semantic-theme-text-tokens.md).

```css
:root {
  --bg:            #0A0A0B;   /* основная поверхность */
  --bg-elevated:   #141417;   /* карточки/секции */
  --text-on-dark:  #F2F2F0;   /* текст на тёмном */
  --text-muted:    #A1A1AA;   /* вторичный (контраст ≥ AA) */
  --accent:        #FF2E7E;   /* один точный акцент */
  --accent-ink:    #0A0A0B;   /* текст на акценте */
  --hairline:      #26262B;   /* тонкие границы 1px */
}
```

### Направления (фон / акцент / характер) — стартовые наборы

Не дефолтные связки; подбирай контраст текста под фон (проверяй computed-цвета).

- **A. Tech / SaaS (тёмный неон):** `--bg #0A0A0B` / `--accent #C5F84A` (кислотный лайм) — спортивный, техно.
- **B. Премиум-тёмный:** `--bg #0E0E10` / `--accent #C9A227` (приглушённое золото) — люкс, дорого.
- **C. Светлый строгий:** `--bg #F4F2EC` / `--ink #0A0A0B` / `--accent #1A4D3A` (тёмно-зелёный) — чисто, статусно.
- **D. Горячий бренд:** `--bg #0A0A0B` / `--accent #FF2E7E` (горячий розовый) — дерзко, заметно.
- **E. Природный/wellness:** `--bg #1B2A24` (хвойный) / `--accent #E8C36B` (тёплый песок) — спокойно, органично.
- **F. Editorial/светлый:** `--bg #FBFAF7` / `--ink #161614` / `--accent #B5341F` (терракот-акцент дозированно) — журнал.

> Эти hex — отправная точка, а не догма: под бриф/референс сдвигай тон, но держи **один** акцент и
> контраст AA+. Избегай дефолтов модели: кремовый `#F4F1EA`+serif и purple→blue градиент.

### Подбор по брифу

1. Референс есть → вытащи доминанту + акцент + нейтрали, нормализуй в токены по поверхностям.
2. Нет → выбери направление по настроению (tech→A, люкс→B, статусный→C, дерзкий→D, wellness→E, контент→F).
3. Зафиксируй токены в `DESIGN-DIRECTION.md`; на них опирается реализация.

### Инструменты

- [Coolors](https://coolors.co) — генерация/итерация палитр.
- [Realtime Colors](https://realtimecolors.com) — примерка палитры на живом UI + проверка контраста.
- [Huemint](https://huemint.com) — AI-палитры под бренд.

## Частые ошибки

- Один глобальный `--text` → светлый текст утекает на светлую секцию.
- Серый текст на цветном/тёмном фоне (gray-on-color) — проваленный контраст.
- Несколько конкурирующих акцентов вместо одного точного.
- Дефолтный кремовый/serif или purple→blue градиент «по привычке».

## Security / performance risks

- Нет прямых security-рисков; следи за контрастом (a11y) — это формальное требование AA.
- Тяжёлые градиент-меши/blur как фон бьют по INP/LCP — держи лёгкими (см. [Performance](Performance.md)).

## Testing strategy

- Контраст по **computed-цветам** (не только по ожидаемым) на тёмных и светлых секциях; AA ≥ 4.5:1 для body.
- Проверка на дальтонизм (Coolors/Realtime Colors имеют симуляцию).
- Тёмные media-карточки внутри светлой секции — текст явно возвращает `--text-on-dark`.

## Edge cases

- Dark/light переключатель: дублируй токены под обе темы, не инвертируй вслепую.
- Акцент на градиенте: проверь читаемость `--accent-ink` в самой светлой и самой тёмной точке.
- Печать/PDF-экспорт лендинга: тёмный фон уводит в чернила — дай print-тему.
