# Source priority

При конфликте источников порядок доверия:

1. Официальная документация.
2. Репозитории maintainers.
3. Зрелые production boilerplates.
4. Engineering статьи с датой и контекстом.
5. Сообщества, Reddit, личные блоги как secondary signal.

Внутренние lessons learned имеют высокий вес для повторения практики, но не должны отменять security и official docs.
