# Freshness checks

Freshness показывает, насколько документ актуален.

## Правила

- Документы по активным frameworks проверять минимум раз в квартал.
- Security/MCP/OpenAI docs проверять перед крупным проектом.
- Устаревшие документы переводить в `status: archived` или обновлять.
- Обновление источника фиксировать в Git-коммите.
