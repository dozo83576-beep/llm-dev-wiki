# llms.txt rules

`llms.txt` должен быть картой для LLM, а не дампом всей вики.

## Содержимое

- Назначение вики.
- Source policy.
- Ключевые входные документы.
- Playbooks.
- Prompts.
- Security rules.
- Запрет на секреты и приватные данные.

Источник: [llms.txt proposal](https://llmstxt.org/).
