# OpenTelemetry

OpenTelemetry стандартизирует traces, metrics и logs. Используй для распределенных систем, где важно видеть путь запроса через frontend, backend, database и внешние API.

Источник: [OpenTelemetry Docs](https://opentelemetry.io/docs/).
