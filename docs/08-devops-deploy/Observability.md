# Observability

Минимум: logs, metrics, traces, error tracking, uptime checks, alerts. Каждый production incident должен приводить к обновлению checklist или failure case.

Ключи: correlation id, user/tenant context без PII, latency, error rate, saturation, external dependency failures.
