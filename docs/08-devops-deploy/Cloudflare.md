# Cloudflare

Cloudflare подходит для DNS, CDN, Workers, Pages, WAF, rate limiting и edge logic. Изменения DNS/WAF требуют отдельной проверки, потому что влияют на доступность продукта.

Источник: [Cloudflare Docs](https://developers.cloudflare.com/).
