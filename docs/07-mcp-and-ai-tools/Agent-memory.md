# Agent memory

Agent memory хранит полезные предпочтения, проектные решения и lessons learned. Она не должна хранить секреты и приватные данные.

## Что сохранять

- Предпочитаемые стеки и архитектурные решения.
- Проверенные паттерны.
- Ошибки, которые нужно не повторять.
- Ссылки на case studies.

## Что не сохранять

- API keys, tokens, cookies.
- Персональные данные клиентов.
- Закрытые коммерческие данные без разрешения.
- Временные гипотезы, которые не были проверены.
