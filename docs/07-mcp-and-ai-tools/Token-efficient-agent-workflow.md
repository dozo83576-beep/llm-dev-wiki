# Token-efficient agent workflow

Цель — дать модели минимум неизвестного ей контекста и сохранить проверяемость.

## Маршрут

1. Прочитай project-local правила и фактическое состояние проекта.
2. Для запроса о сайте получи `routeMode` через `tools/new-site-preflight.ps1`.
3. В `direct` работай нативно без pipeline state и загружай только релевантные документы.
4. В `full-pipeline` продолжай contract v2 по существующим артефактам; читай skill и wiki только текущей фазы.
5. Используй внешний инструмент лишь для внешнего факта, действия или фактической проверки.
6. Запусти проверки, пропорциональные изменённому поведению и риску.

## Когда использовать

Для любой многошаговой задачи, где нужно ограничить объём обязательных чтений, helpers и внешних tools без потери acceptance gates.

## Когда не использовать

Не превращай workflow в обязательную пошаговую церемонию для однострочной правки или простого ответа.

## Контекст задачи

Достаточно указать путь, цель, ограничения, критерии готовности и известные команды проверки. Не загружай весь corpus, зависимости и generated files без причины.

Для существующего проекта сначала найди entrypoints, scripts, local gates и затронутые границы. Стек не пересматривай, если это не требуется задачей. Для нового простого публичного сайта default — static Astro; server runtime добавляется только по требованиям.

## Инструменты

- Официальная актуальная документация — для версий, API, лицензий и security guidance.
- Браузер — для поведения и визуального evidence, а не для замены design reasoning.
- Внешние аккаунты — только для явно разрешённых операций с проверяемой целью и откатом.
- Production/DNS/billing — после отдельного approval.

## Проверка

Используй существующие test/lint/typecheck/build команды. Browser smoke нужен при изменении наблюдаемого UI; dry-run — при рискованной внешней мутации, а не как ритуал для каждой локальной правки.

## Частые ошибки

Читать всю вики, запускать full-pipeline для hero-правки, подключать helper «на всякий случай» или считать отсутствие optional tool блокером.
