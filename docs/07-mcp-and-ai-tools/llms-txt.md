# llms.txt

`llms.txt` — Markdown-ориентированный индекс для LLM-клиентов. Для этой вики он нужен как краткая карта важных документов, правил источников и маршрутов чтения.

## Production-паттерны

- Держи `llms.txt` коротким: overview, core docs, playbooks, prompts, source policy.
- Не включай секреты и приватные кейсы.
- Обновляй при добавлении крупных разделов.
- Для больших vault используй `llms-full.txt` только если он не содержит закрытых данных.

## Проверка

- Все ссылки из `llms.txt` открываются.
- Документ не дублирует всю вики.
- Есть дата обновления и назначение.

Источник: [llms.txt proposal](https://llmstxt.org/).
