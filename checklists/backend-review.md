# Backend review checklist

- [ ] Входные данные валидируются на границе API.
- [ ] Authorization проверяется до доступа к объектам.
- [ ] Бизнес-логика не находится в controller/route handler.
- [ ] Ошибки возвращаются единым контрактом.
- [ ] Внешние запросы имеют timeout и обработку failures.
- [ ] Транзакции покрывают целостные бизнес-операции.
- [ ] Логи structured и не содержат секреты.
- [ ] Есть unit/integration tests для критичной логики.
