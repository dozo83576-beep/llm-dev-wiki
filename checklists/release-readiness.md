# Release readiness checklist

- [ ] Локальные проверки прошли: lint/typecheck/tests/build.
- [ ] Миграции проверены и имеют rollback-план.
- [ ] Environment variables настроены для target environment.
- [ ] Preview/staging проверен по критичным сценариям.
- [ ] Monitoring, error tracking и alerts включены.
- [ ] Security review пройден.
- [ ] Документация deploy/rollback обновлена.
- [ ] После релиза запланирована запись в `case-studies` или `lessons-learned`.
