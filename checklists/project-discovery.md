# Project discovery checklist

- [ ] Цель проекта сформулирована одним предложением.
- [ ] Определены пользователи, роли и ключевые сценарии.
- [ ] Зафиксированы критерии приемки.
- [ ] Выбран тип проекта из [[../docs/01-development-process/stack-selection|матрицы стеков]].
- [ ] Известны интеграции, платежи, email, analytics, AI/API.
- [ ] Определены данные, которые нельзя сохранять в вики.
- [ ] Зафиксированы ограничения: сроки, бюджет, hosting, compliance, поддержка.
- [ ] Определен минимальный набор тестов для приемки.
