# AI agent review checklist

- [ ] Агент получил только нужные инструменты и директории.
- [ ] Мутации требуют подтверждения или ограничены рабочей областью.
- [ ] Агент не видел секреты и приватные данные.
- [ ] План действий был сформулирован до изменений.
- [ ] Изменения проверены командами, а не только описаны.
- [ ] Успешные приемы сохранены в `case-studies/successes` или `patterns`.
- [ ] Ошибки сохранены в `case-studies/failures` с правилом предотвращения.
