# FastAPI + PostgreSQL

Подходит для AI-heavy backend, ML-интеграций, data pipelines и API, где Python-экосистема важнее TypeScript-единства.

Состав: FastAPI, Pydantic, SQLAlchemy, Alembic, PostgreSQL, Redis/RQ/Celery для фоновых задач, pytest, OpenAPI.

Источники: [FastAPI Docs](https://fastapi.tiangolo.com/), [SQLAlchemy Docs](https://docs.sqlalchemy.org/).
