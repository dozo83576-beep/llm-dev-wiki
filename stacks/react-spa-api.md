# React SPA + API

Выбирай, когда frontend и backend должны деплоиться отдельно, API уже существует или приложение работает за корпоративным шлюзом.

Состав: React + Vite + TypeScript, TanStack Query, React Hook Form + Zod, backend на NestJS/FastAPI/Fastify, OpenAPI-контракт, Playwright smoke-тесты.

Не выбирай для SEO-зависимых сайтов: SPA сложнее индексировать и дороже оптимизировать.
