# Laravel

Laravel подходит для PHP-команд, классических web-приложений, CRUD, e-commerce и админок. Сильные стороны: routing, Eloquent ORM, queues, jobs, migrations, auth scaffolding, богатая экосистема.

Не выбирай, если проект уже стандартизирован на TypeScript/Python или нужен тесный React Server Components workflow.

Источник: [Laravel Docs](https://laravel.com/docs).
