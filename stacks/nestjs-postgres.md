# NestJS + PostgreSQL

Подходит для сложного TypeScript-backend: модули, роли, интеграции, очереди, cron, webhooks, domain services.

Используй модульную структуру NestJS: controller принимает HTTP, service содержит бизнес-логику, repository/ORM работает с данными, DTO валидируются на входе. Для БД по умолчанию PostgreSQL + Prisma/Drizzle.

Источники: [NestJS Docs](https://docs.nestjs.com/), [PostgreSQL Docs](https://www.postgresql.org/docs/).
