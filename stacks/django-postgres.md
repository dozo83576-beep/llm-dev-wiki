# Django + PostgreSQL

Выбирай для enterprise CRUD, админок, проектов с сильной серверной моделью и быстрым backend-start. Django дает ORM, admin, auth, migrations и зрелую экосистему.

Не выбирай, если команде нужен единый TypeScript stack или UI полностью строится вокруг React Server Components.

Источник: [Django Docs](https://docs.djangoproject.com/).
