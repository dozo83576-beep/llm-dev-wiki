# Pattern: Full-height first screen (контроль сгиба)

## Назначение

Сделать так, чтобы первый экран состоял ровно из двух блоков (например Hero + нижняя полоса —
лента марок, статистика, CTA), а следующая секция начиналась **точно на сгибе** и не выглядывала
над ним узкой «полосой». Hero при этом растягивается на свободную высоту окна.

## Когда использовать

- Лендинг/маркетинговая страница, где первый экран должен быть «цельным», без случайной полоски
  следующей секции внизу.
- Нужно, чтобы Hero масштабировался под высоту окна, а вспомогательная полоса была прижата к низу
  первого экрана.

## Когда не использовать

- Контент первого экрана заведомо выше окна (длинный текст/форма) — тогда фиксировать сгиб
  бессмысленно.
- Мобильные экраны: на узких вьюпортах full-height-блок делает Hero неуместно высоким — паттерн
  применяют только от планшета и выше.

## Структура

Обернуть две соседние секции в один flex-контейнер высотой в первый экран:

- `.first-screen{display:flex; flex-direction:column}`.
- На ширине ≥ tablet: `min-height: calc(100dvh - var(--header-height))` (с `100vh`-фолбэком для
  старых браузеров). Если шапка `position: sticky` и в потоке — она занимает свою высоту сверху,
  поэтому из `100dvh` вычитается её высота, и шапка + первый экран = ровно `100dvh`.
- Верхний блок (Hero) — `flex: 1 1 auto` (растягивается).
- Нижняя полоса — `flex: 0 0 auto` (натуральная высота, прижата к низу).
- Внутреннее центрирование Hero (`display:grid; align-items:center` и т.п.) не трогается — `flex`
  управляет только высотой Hero как flex-элемента.

## Реализация (пример)

```css
.first-screen { display: flex; flex-direction: column; }

@media (min-width: 641px) {
  .first-screen {
    min-height: calc(100vh - var(--header-height));   /* фолбэк */
    min-height: calc(100dvh - var(--header-height));  /* мобайл-safe (адресная строка) */
  }
  .first-screen .hero        { flex: 1 1 auto; }  /* растягивается */
  .first-screen .brand-strip { flex: 0 0 auto; }  /* прижата к низу */
}
```

```html
<div class="first-screen">
  <section class="hero">…</section>
  <section class="brand-strip">…</section>
</div>
```

## Production-паттерны

- Всегда давать `100vh`-фолбэк перед `100dvh` (на десктопе разницы нет, на мобиле `dvh` корректно
  учитывает адресную строку).
- Hero оставлять с собственным `min-height` как нижним полом — на случай, когда контент+полоса ниже
  экрана и flex-контейнер не растягивается.
- Декоративные фоновые изображения — `object-fit: cover`, чтобы при росте Hero не искажались.

## Частые ошибки

- **Главная ошибка:** пытаться «поймать» сгиб уменьшением `min-height`/паддингов числами. Если под
  центрированным контентом видна пустота, высоту секции задаёт **контент**, а не `min-height` —
  подгонкой чисел сгиб не зафиксировать на всех высотах окна. Нужен структурный flex + `dvh`.
- Забыть `dvh`-фолбэк → дёрганье высоты на мобиле при сворачивании адресной строки.
- Навязать full-height на мобиле → Hero становится неуместно высоким; ограничивать брейкпоинтом.

## Альтернативы

- `100dvh`-Hero без нижней полосы (полоса уезжает под сгиб) — проще, но теряется «цельный» первый
  экран.
- Точечная подгонка паддингов под конкретную высоту окна — хрупко, ломается на других экранах.
