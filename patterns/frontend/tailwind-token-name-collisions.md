# Коллизия имён токенов Tailwind v4 со шкалами утилит

## Назначение

Не дать цветовому токену в `@theme` перехватить встроенную утилиту другого назначения. Дефект тихий:
сборка зелёная, типизация чистая, консоль пустая — текст просто исчезает со страницы.

## Проблема

Tailwind v4 генерирует утилиты из имён токенов. Токен `--color-base` порождает **цветовую** утилиту
`text-base`, которая перебивает встроенную одноимённую утилиту **размера шрифта**.

```css
@theme {
  --color-base: #0f1115;   /* фон страницы */
}
```

Любой `class="text-base"`, поставленный как размер, красит текст в цвет фона. На проекте так
исчезли заголовки FAQ: элементы в DOM, содержимое на месте, контраст 1:1.

Ни одна автоматическая проверка не сработала: `astro build` зелёный, `astro check` — 0 ошибок,
консоль браузера чистая. Ловится только вычисленным контрастом или глазами.

## Решение

Именовать цветовые токены по роли поверхности, а не словом из шкалы:

```css
@theme {
  --color-surface: #0f1115;
  --color-surface-raised: #171a21;
  --color-ink: #e7e9ee;
}
```

Занятые имена, которые нельзя брать под цвет: `base`, `sm`, `md`, `lg`, `xl`, `2xl`…,
`light`, `normal`, `medium`, `semibold`, `bold`, `thin`.

## Как поймать

Регрессионный тест на вычисленный контраст по всем текстовым элементам страницы — он же ловит
и обычные ошибки палитры. Проверять `getComputedStyle` живой страницы, а не исходный CSS:
коллизия проявляется только после каскада.
