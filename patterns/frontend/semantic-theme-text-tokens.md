# Semantic theme text tokens

## Назначение

Паттерн предотвращает белый или слишком светлый текст на светлых секциях, когда страница смешивает темные hero-блоки, светлые контентные секции и карточки поверх изображений.

## Когда использовать

- Лендинг или промо-страница содержит и dark, и light sections.
- Глобальная переменная `--text` была создана для одной темы, но используется в разных цветовых контекстах.
- Визуальное ревью показывает, что отдельные `span`, `button`, `li` или подписи не попадают под общие правила для `p` и заголовков.

## Когда не использовать

Не усложняй палитру, если весь интерфейс живет на одной поверхности и контраст уже проверен. Для полноценной дизайн-системы с несколькими брендами лучше описывать токены на уровне темы и компонентов.

## Структура

- Базовые токены задают не цвет "вообще", а цвет на поверхности: `--text-on-dark`, `--text-on-light`, `--text-on-light-muted`.
- Секция или контейнер задает свой цвет текста через `color`, а компоненты внутри переопределяют только исключения.
- Для темных media cards внутри светлой секции явно возвращай `--text-on-dark`, иначе наследование от секции сделает текст слишком темным на фото.
- Проверяй не только CSS-правило, а фактический computed style у выбранных элементов.

## Реализация (пример)

```css
:root {
  --text-on-dark: #f7efd8;
  --text-on-light: #17130c;
  --text-on-light-muted: #5e574c;
}

.page {
  color: var(--text-on-dark);
}

.section--light {
  background: #e3dfd6;
  color: var(--text-on-light);
}

.section--light .muted,
.section--light p,
.section--light li {
  color: var(--text-on-light-muted);
}

.section--light .media-card {
  color: var(--text-on-dark);
}
```

## Production-паттерны

Визуальный smoke должен включать минимум одну темную секцию, одну светлую секцию, FAQ/accordion, форму и карточки поверх изображений. Для спорных мест измеряй contrast ratio по computed color и фактическому background.

## Частые ошибки

- Называть переменную `--text`, хотя она подходит только для темного фона.
- Переопределять только `p`, забывая `span`, `button`, `li`, `label`.
- Исправлять один выбранный элемент вместо контейнерной темы.
- Менять текст на чисто черный или белый без учета бренда и визуального тона.

## Альтернативы

Для Tailwind-проектов тот же принцип переносится в theme tokens и utility-классы поверхности. Для React-дизайн-системы лучше закрепить цветовые роли в компонентах `Surface`, `Card`, `Text`.
