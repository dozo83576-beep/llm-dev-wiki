# Pattern: Layout archetypes

## Назначение

Каталог архетипов компоновки hero и секций — чтобы осознанно выбрать структуру ДО кода и не
сходиться к дефолтному «hero + 3 карточки в ряд». Это описания-варианты (ДНК компоновки), а **не
копии чужой вёрстки**. Питает шаг выбора осей из
[Anti-AI-slop design](anti-ai-slop-design.md) (анти-повторяемость).

## Когда использовать

- Старт лендинга/продающей страницы: выбрать hero-архетип и ритм секций под нишу/настроение.
- Дизайн «как у всех» — нужно сознательно уйти от дефолтной сетки.
- Несколько проектов подряд — чтобы не повторять одну и ту же компоновку.

## Когда не использовать

- Дашборд/админка — там структура диктуется данными (см. [UI-architecture](../../docs/02-frontend/UI-architecture.md)).
- Жёсткий бренд-гайд/макет от клиента уже задаёт компоновку.

## Структура

### Hero-архетипы (выбрать один)

- **Split** — текст слева / медиа справа (или наоборот). Надёжно, но затёрто — оживляй асимметрией.
- **Centered statement** — крупный типографический оффер по центру, минимум элементов. Сильно с display-шрифтом.
- **Asymmetric / off-grid** — заголовок и медиа смещены, наложения, разрыв сетки. Дорого, «агентство».
- **Typographic hero** — гигантский текст-оффер во весь экран, медиа второстепенно/фоном.
- **Full-bleed media** — фуллскрин фото/видео + минимальный оверлей-оффер. Для бренд/премиум.
- **Bento** — модульная сетка плиток разного размера на первом экране (продукт/фичи сразу).
- **Editorial** — журнальная сетка: колонки, рубрики, mono-метки, hairline-разделители.
- **Product-first** — крупный скрин/мокап продукта как герой (SaaS), оффер компактно сбоку/сверху.

### Оси вариативности (фиксируй на проект)

1. Hero-архетип (из списка) — и не тот же, что в прошлом проекте.
2. Ритм секций: плотный vs воздушный; одинаковый vs чередующийся фон поверхностей.
3. Сетка: симметрия vs асимметрия/наложения; ширина контейнера.
4. Акцентные приёмы: ghost-числа, mono-индексы секций, hairline, угловые маркеры.

### Архетипы секций (комбинируй, не повторяй один шаблон)

- Фичи: bento / зебра-ряды (текст↔медиа по очереди) / нумерованный список с крупными индексами.
- Соц.док: marquee логотипов / крупная цитата-кейс / метрики counter-up.
- Прайс: 2–3 плана с одним выделенным / таблица сравнения / калькулятор.
- CTA: full-bleed акцентная полоса / асимметричный блок с формой.

## Реализация (пример)

```html
<!-- Asymmetric hero: смещённый заголовок + наложение медиа -->
<section class="hero">
  <p class="index">[001] / 2026</p>           <!-- mono-метка -->
  <h1 class="display">Большой характерный оффер</h1>
  <figure class="media media--overlap">…</figure> <!-- наложение на колонку текста -->
</section>
```
```css
.hero { display: grid; grid-template-columns: 1.4fr .9fr; gap: clamp(1rem, 4vw, 4rem); align-items: end; }
.media--overlap { margin-left: -8%; }            /* разрыв сетки */
.index { font-family: var(--font-mono); color: var(--text-muted); }
```

## Production-паттерны

- Архетип выбирается в `DESIGN-DIRECTION.md` вместе со шрифтами/палитрой, до кода.
- Минимум 2–3 разных архетипа секций на странице — иначе ритм монотонный.
- Каждый архетип всё равно проходит остальные правила: токены по поверхностям, motion-бюджет, a11y.
- **Тёмная тема на многих full-height секциях подряд легко читается монотонно, даже если архетипы
  секций разные** — один и тот же почти-чёрный фон везде не даёт визуального разграничения между
  блоками. Если единственная светлая поверхность в палитре (инвертированная секция) стоит лишь в
  одном месте страницы, добавь ещё один — третий — тон: alternate-dark токен на ~1.5–1.6× светлее
  базового (тот же оттенок, просто светлее), и назначь его вразброс по секциям так, чтобы никакие два
  соседних блока не делили один и тот же не-базовый тон. Итог — реальный ритм (тёмный / чуть
  светлее-тёмный / светлый / тёмный …) без полного редизайна в светлую тему и без правки разметки
  внутри каждой секции — только смена `bg-*` класса на обёртке секции.
  ```css
  --color-void:  #14100c; /* базовый холст */
  --color-umber: #211a14; /* альтернативный тёмный тон, ~1.6× светлее, тот же оттенок */
  --color-linen: #ede6db; /* единственная светлая поверхность */
  ```

## Частые ошибки

- Дефолт «hero + 3 карточки» как единственная структура.
- Один и тот же архетип во всех секциях подряд (монотонность).
- Асимметрия ради асимметрии без сетки — рассыпается на мобильном.
- Копирование чужого макета пиксель-в-пиксель вместо извлечения принципа.

## Альтернативы

- Шаблон CMS/конструктора (Webflow/Tilda) — когда нужен скорость и типовой результат, а не уникальность.
- Строгая дизайн-система с фиксированными блоками — для масштабных контентных сайтов.
