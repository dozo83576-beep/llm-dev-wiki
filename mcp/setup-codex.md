# Codex MCP setup

Для Codex используй доступные плагины и инструменты:

- GitHub для репозиториев и PR.
- Browser для локальных web targets.
- OpenAI Developers для OpenAI API и Agents SDK.
- Vercel/Cloudflare/Render для deployment-документации и логов.
- context7 для актуальной документации библиотек.

Перед работой агент должен прочитать `AGENTS.md`, затем relevant docs/checklists.
